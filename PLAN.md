# Football Intelligence Engine development plan

1. Verify the existing course template and map its requirements to deliverables.
2. Pin and validate complete public Premier League seasons. Reserve the last season for final evaluation.
3. Build date-batched historical features and tests for leakage. Run development and validation comparisons against simple baselines.
4. Document the reference algorithms and student implementation work. Build executable case studies.
5. Serve a versioned reference artifact through the template API and local UI. Verify prediction and failure paths.
6. Record reproducible commands, measured results, remaining course requirements, and GitHub status.

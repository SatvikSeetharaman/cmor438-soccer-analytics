# Course package provenance

The [official course repository](https://github.com/RandyRDavila/Data-Science-Machine-Learning-Fall-2026)
was examined at commit `b697d54af35e43f9d5032d01d77fbc291d947aeb`. Relevant
materials were lecture 10 on gradient descent, lecture 11 on logistic decisions
and hinge loss, and `rice_dsm.ml` implementations for multiclass softmax,
nearest neighbors and trees. The official project template is inherited at
`ea74d66` in this clone.

The lockfile has no `rice_dsm` dependency. The reference experiments call
scikit-learn estimators and the template candidate catalog. The template
provides the demonstrated dataset, registry, bundle, logging and API contracts.
Local football code extends those boundaries with pinned ingestion,
date-batched features and historical evaluation. Course code was consulted
for learning and verification design. No upstream educational estimator was
copied into the student package.

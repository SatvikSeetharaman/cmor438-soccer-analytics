## Recommended practices

The [milestones](../MILESTONES.md) and [contributing guide](../CONTRIBUTING.md)
recommend a verified estimator slice first, one issue per focused branch, clean
builds, explicit data and science review, phased model selection, then full
operations and release. The milestone list is guidance on sequencing.

## Optional enhancements

Cross-league validation, event-level historical expected goals, matchday rest,
class-specific recalibration, and a validated fixture schedule could improve a
later study. The current choice keeps downloads below one megabyte and centers
the report on complete Premier League seasons.
